# Karibu Content

This folder separates source medical material from generated and published **Karibu Learn** content.

Karibu Learn is a standalone app (not Karibu EHR). Content here feeds Learn only — no PHI, no EHR patient linkage. Product boundary: [`docs/karibu-learn/product-boundary.md`](../docs/karibu-learn/product-boundary.md).

## Folders

- `medical-corpus`: metadata and references for approved source material.
- `learn/source`: human-authored or reviewed source inputs for learning content.
- `learn/generated`: machine-generated draft outputs.
- `learn/reviewed`: clinically and educationally reviewed candidate packs.
- `learn/published`: immutable published learning packs.
